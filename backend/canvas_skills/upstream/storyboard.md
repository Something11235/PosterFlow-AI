## 工作流

1. **排定戏剧落点与悬念时机**：顺场理清动作、对白、音效、画面文字与转折落点（若立项或剧本限定了“后半段 / 最后 N 秒首次露面”，按全集目标时长换算到具体秒数位置再排镜）。
2. **逐镜写清起止、运镜与声音**：顺着 `起点 → 动作 → 终点` 交代人物站位、姿态与持物交接，单镜动作量贴合秒数（见 [镜头设计方法](references/shot-craft.md)）：
   - `运镜`：运动镜头写清动法与起止落点（开场强钩子或高潮反转可用急推）；固定镜头直接写 `固定`，无需强凑不动理由。
   - `声音`：排镜时按台词与停顿估准秒数，文档「声音」行清爽写明对白/VO/OS、关键音效与留白即可，免写读秒算术账。

## 1. 场次覆盖、节拍拆镜与动作衔接（`SHT-01` / `SHT-08`）

| 剧本节拍类型 | 拆镜与环境带出做法 |
|---|---|
| 一句台词配一个顺手动作 | 目的与起止变化清楚时合在一镜拍完 |
| 连转话锋或逼出听者变脸 | 按双方攻守转换与听者反应节点切开 |
| 爆发推搡或连环动作 | 单镜装不下时按发力阶段拆开，切点锁死双方距离与手位；掌掴等干脆单招一镜落定 |
| 沉默对视或硬憋不响 | 接住重击或暗下决心时单给一镜，不硬塞咽口水、搓手等凑数小动作 |

## 2. 镜头目的、接招反应与悬念藏露（`SHT-02` / `SHT-12`）

- **镜头目的（`SHT-02`）**：写明本镜让观众新看懂了什么或场上谁的处境变了（谁堵住退路、亮出铁证、攻守易主、压住悬念），不拿“中景展示两人说话”敷衍。
- **给足接招反应（`craft_default`）**：重话砸出、当众拆穿或局势翻盘时，画面要交代受影响一方怎么接住这记重击——可单切反应近景、双人同框拍对方僵住后撤，也可借全场死寂或茶面细纹落定；切镜密度与景别随戏份轻重和项目节奏定，同框已演透时不必多切一刀。
