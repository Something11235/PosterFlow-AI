# PPT Master · Quick Generate 网页工作流

网页工作区参考 PPT Master 6.10.0 Quick Generate 的资料整理、整稿规划和逐页制作方法。大纲与各页分别生成，页面使用 1280 × 720 的可编辑对象。网页预览和 PowerPoint 导出读取同一份元素。

1. 阅读主题、受众、页数、模板文字及参考材料。引文、数字、单位和来源应可在资料中核实。用户指定演示语言时按其要求撰写。
2. 编排大纲。每页确定一个结论，记录适合的比较、顺序或关系构图和可用的证据。将整稿通用的背景色、文字色、强调色、标题及正文字号和对齐方式一起保存。显式设计要求优先，其余设置参考模板的文字槽位、层级和颜色。
3. 逐页制作。每次使用已保存的整稿设定、本页目标与相应资料摘录，让结论落实为可编辑的标题、文字、几何形状和标签。在标题页、内容页和结尾页分别选择合适的构图，保证跨页的阅读节奏。
4. 检查元素边界、文字空间、阅读顺序、对比度和标识符。生成过程中可先预览文字与成形的元素，完整页面经结构校验后保存。导出时按已保存页面的顺序生成 PPTX。
5. 局部修改时，沿用原页的视觉语言和参数，在选区内完成调整。
