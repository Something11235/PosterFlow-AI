# PPT Master · Quick Generate 网页工作流

采用随应用发布的 PPT Master 6.10.0 Quick Generate 单次生成流程。运行环境提供 1280 × 720 的可编辑页面对象。以调用方提供的 JSON 格式交付，使网页和 PowerPoint 读取同一份元素。

1. 阅读主题、受众、页数和资料。先决定每一页要传达的一个结论，按讲述顺序编排。仅在资料提供证据时使用数字、引语和来源。主题与资料语言决定文稿语言。
2. 如提供模板，先检查样板页面、文字槽位、主色和背景，在标题页、内容页和结尾页复用合适的版式。显式修改要求优先。无模板时选择与主题相符的一套色彩、字级和网格。
3. 每页根据内容选择表达方式。例如时间用顺序排列，比较用对齐的列展示，关系用形状与标签表示。维持跨页标题和页边距的一致性，根据内容改变页面构图。控制字号和字数以便投影阅读。
4. 在交付前检查边界、文字空间、阅读顺序、对比度和内容重复。只引用参考资料中实际提供的图像标识。每个可编辑要素持有独立稳定的 id。
5. 局部修改沿用原页的视觉语言，只调整被选中的元素。整页修改可调整页面结构，其余页维持原样。
