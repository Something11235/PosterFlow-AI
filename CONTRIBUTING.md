# Contributing

1. Create a feature branch from `main`.
2. Never add real API keys, generated user images, or local history files.
3. Run `npm run lint` and `npm run build` in `frontend`.
4. Run `python -m compileall -q backend legacy` from the project root.
5. Keep pull requests focused and describe user-visible behavior and verification steps.

Bug reports should include the operating system, browser, deployment method, provider type, error code, and sanitized logs. Do not include API keys.
