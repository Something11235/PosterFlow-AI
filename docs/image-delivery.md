# 原图预览与下载

画廊先显示缩略图；放大、单张下载、画布与 ZIP 通过 `frontend/src/lib/client.js` 读取原图。原图仍从私有 Storage 的临时签名地址读取，不通过 Vercel 代理大文件，也不向 Storage 发送平台 Bearer。

- 签名地址获取最多等待 15 秒，包含 JSON 响应体；失败后保留既有同源鉴权回退。
- 每次原图读取最多等待 45 秒，包含完整文件响应体。签名回退与首次过期鉴权刷新可能使整次操作长于 45 秒，但每一步都有期限；不会无限等待。
- 到期中止网络请求，并主动结束等待；即使底层没有响应 abort，也释放共享等待记录。迟到的结果不会回填缓存。
- 同账号、同图的预览/下载继续共享正常请求与内存缓存；失败后可再次请求。缓存仍按身份隔离，退出账号清空。
- 预览显示加载状态；读取失败或解码失败显示原因和“重新加载原图”。重试重新获取签名与原图，不重新生成、不扣积分。关闭预览不会取消其他操作共享的读取。
- 单张下载显示读取中并禁用重复点击，完成后提示“已请求浏览器下载原图”；这表示已触发下载，不声称文件已保存到磁盘。失败后恢复按钮，可重新尝试。
- 超时、网络失败、404/过期、空文件和图片解码失败分别提供明确提示，不把签名 URL、token 或未经证实的根因呈现给用户。

此次修复解决无限等待和缺少反馈，不代表能消除用户网络到 Storage 的连接问题。后台生成成功、存储对象存在及签名接口 200，也不能证明客户端已经读完原图。

回归测试：`node --test frontend/tests/imageDelivery.test.mjs`，覆盖签名与响应体卡住、共享读取超时、失败后重试、迟到响应不入缓存、凭据隔离及正常缓存/ZIP 路径。界面变更还需桌面和手机模拟验证。

## 备用下载与画布失败重试

原图预览窗口新增“备用下载”，即使普通原图读取仍在等待也能使用。第一步获取新的原图临时地址，第二步点击“打开原图并下载”，交给浏览器处理，避免异步自动弹窗被拦截。它不等待共享 Blob、不发送原图 fetch、不重新生图、不扣积分。远端链接只允许无内嵌凭据的 HTTPS，保留签名并添加 download 参数；同源回退使用已有鉴权下载路由。外链使用 noopener/noreferrer、no-referrer，不把本站 Bearer 或自带 Key 带到存储站点。地址只在当前预览内存中，关闭、换图或认证状态变化后清除。

备用下载仍直连原存储，不经 Vercel 代理图片内容；不能保证解决网络线路问题。浏览器可能直接下载，也可能先显示图片，取决于服务端响应与浏览器行为。

画布导入失败会在上方保留失败列表和具体提示，可点击“重试导入失败图片”。列表只存在本次页面内存，不增加云端图片历史，也不跨刷新保存。批量导入中，已读取成功的图片可以先加入画布；重试只重新签名读取失败项，成功项不重复插入。导入期间禁用并发操作，解码/渲染失败会撤销该批次新插入的对象，保留原有画布内容。认证状态变化或画布卸载后，旧读取结果不会继续启动导入。
