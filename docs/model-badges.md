# 图片模型角标

2026-11-05：本地实现，尚未提交、推送或部署，正式数据库未变更。

默认仅 GPT Image 2.6 Flare、GPT Image 2.6 Sunburst 为红色“热”；（即梦）Seedream 5.0 Pro、Lite、Flash 为红色“新”；其他图片模型无角标。

管理员控制台的“图片模型角标”先下拉选择模型，再为当前模型选择“无／新／热”。切换模型保留各自未保存草稿，点击“保存模型角标”后写入共享配置。当前页面立即同步，其他访客刷新或在可见页面定期读取后同步。设置影响图像工作区、无限画布、服务设置中的模型选择器，以及模型一览。仅展示角标，不修改模型接口、功能限制或价格。

选择器支持键盘上下键、Home/End、Enter/空格确认、Esc 关闭和输入名称查找。列表用 portal 避免被画布或弹窗滚动容器裁切。

## 数据与权限

- `GET /api/model-badges` 只返回 revision 和模型角标；公开读取不返回编辑者或其他管理数据。
- `/api/admin/model-badges` GET/POST 使用已有管理员权限检查，兼容配置的管理员名单与 profile 管理员角色。POST 限流、限制来源和请求大小，严格校验十款模型及固定枚举。
- 保存携带 revision；数据库锁定单例并比较版本，冲突返回 409。后台保留草稿，重新加载后才能继续保存。失败不显示成功；组件卸载或认证变化时取消客户端等待。
- `private.model_badge_settings` 开启 RLS，客户端角色无表与 RPC 权限；public 包装 RPC 仅 service_role 可执行，内部函数使用空 search_path。写入再次核验活跃且未删除的账户，管理员授权由 Flask 检查。
- 默认值只由新增迁移初始化一次。再次部署不会覆盖已编辑的配置。未配置本地数据库时公开读取可回退默认角标，管理保存不可伪装成功；数据库暂时不可用时界面保留当前可用角标。
