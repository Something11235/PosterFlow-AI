# PosterFlow AI UI/UX 规范

## 产品定位

PosterFlow AI 是面向多类型图片创作的专业工作台，覆盖宣传海报、摄影、插画、3D 渲染、像素艺术、Logo 设计、产品展示和线稿上色。界面使用深石墨底、冷蓝主色、mint 成功色和 gold 参数强调，保持商务科技质感，不使用卡通化装饰。

## 页面结构

- 左侧导航：品牌识别、文生图、图生图、局部重绘、历史复用和图片服务入口。
- 顶部状态栏：当前模式、画幅、当前预设、画质、批量数量和服务商状态。
- 预设库：类别筛选、内置预设、用户自定义预设、封面、模板载入、编辑/删除和 JSON 导入导出。
- 提示词编辑器：当前预设信息、可编辑完整 prompt、字符状态、复制、参考图上传和主生成按钮。
- 参数面板：画面尺寸、画质、批量数量、参考强度。
- 右侧画廊：空状态、生成骨架、错误诊断、结果网格、原图放大、下载、批量 ZIP 导出和局部重绘。
- 服务配置弹窗：服务商预设、自定义接口、API Key、模型标识、鉴权方式和配置检查。

## 生成模式

### 独立生成

文生图和图生图调用 `/api/generate`。每次请求只发送当前编辑器 prompt；图生图额外发送本次选择的参考图。程序不从上一轮结果自动继承文字或图片。

### 局部重绘

首次请求调用 `/api/generate`，可选参考图。已有结果后再次点击主按钮或画廊中的迭代按钮调用 `/api/modify`，自动使用上一轮图片作为参考，只提交本次追加要求。参考强度控制重绘幅度。

## 组件拆分

- `App.jsx`：全局状态、模式逻辑、服务请求、历史抽屉、预览弹窗。
- `Sidebar.jsx`：品牌区、功能模式、服务配置和历史入口。
- `PresetLibrary.jsx`：预设筛选、创建、编辑、删除、封面上传、导入导出。
- `PromptEditor.jsx`：通用 prompt 编辑、复制、参考图和生成按钮。
- `ParameterPanel.jsx`：尺寸、画质、数量、参考强度。
- `Gallery.jsx`：结果展示、空/加载/错误状态、选择、下载和重绘。
- `ProviderSettings.jsx`：多服务商配置及会话级 Key 管理。

## 交互与无障碍

- 所有主要触控目标高度不低于 44px，按钮有明确 hover、focus、disabled 和 loading 状态。
- 表单使用可见 label、helper text、近场错误提示和 `role="alert"`。
- 弹窗支持 Escape 关闭，遮罩层保证前景层级；密码字段提供显示/隐藏按钮。
- 375px、390px、桌面宽度均不产生横向滚动；移动端使用底部抽屉式弹窗。
- 遵循 `prefers-reduced-motion`，动画只表达状态变化，不使用装饰性大动画。
- 使用 Lucide 图标，不使用 emoji 作为结构性图标。

## 数据与安全

- 浏览器 Key 只进入请求头 `X-Provider-Api-Key`，不写入历史和预设 JSON。
- 自定义预设封面与模板保存在浏览器 IndexedDB，可用 JSON 导入导出迁移。
- 后端支持 HTTPS OpenAI 兼容端点，并默认阻止 localhost、私网 IP 和不安全 HTTP，降低 SSRF 风险。
- 公网共享服务还需要在部署层增加认证、限流、配额和数据库/对象存储。
