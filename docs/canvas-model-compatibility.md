# 无限画布模型兼容与选区编辑

2026-10-30：普通图片导入、排列、缩放和导出使用统一画布链路。六款生图模型均可在 AI 图片框内生成。新增三模型通过明确的比例标识传递七种画框比例，参考图编辑使用源图比例，避免将近似像素尺寸约分后误判为不支持。

## 编辑方式

- 原有三个 GPT 图片模型：参考图与 Alpha PNG 蒙版编辑。矩形、圆形和画笔定义修改选区；文字、箭头只作为说明。蒙版像素尺寸匹配第一张实际上传主图，透明区表示修改。蒙版独立传递，不作为普通参考图。服务端在积分预留前校验格式、大小、尺寸及透明区域，兼容剔除旧客户端误混入参考图列表的蒙版路径。
- Nano Banana 2.1、Grok Imagine Image 2.0：参考图及文字指令编辑，附带标注说明图；不声明精确蒙版支持。标注图占用一个参考图名额，超过上限会阻止提交，不静默丢弃标注。
- Grok Imagine 2.0 Ext：画布支持单张原图的矩形与圆形选区，不支持多图合成或画笔选区。旋转、缩放后的选区转为归一化多边形并裁到主图边界。普通创作页仍保持文生图接口，不能把此功能理解为通用参考图编辑。

## Grok Ext 流程与边界

采用官方 [segment / region_edit 协议](https://docs.apimart.ai/cn/api-reference/images/grok-imagine-2.0-ext/layer-region-edit)：鉴权与素材作用域校验 → 上传原图 → 一次免费 segment 提交 → 仅查询该任务 → 服务端返回绑定账户、Key 作用域和有效期的资产凭证 → 预留积分 → 只提交一次 region_edit → 查询原任务并沿用既有保存、结算与退款。

浏览器不能直接提供未经验证的 image_id。服务端验证多边形点数、有限坐标、边界、凸性和非零面积；收费请求只使用验证后的资产。准备阶段失败或不确定不会提交收费编辑；已受理收费请求不自动重发。凭证和资产 ID 不写历史、日志或独立数据库字段。

复用当前 Grok Ext 每张成功结果 1 网站积分、自带 Key 零网站积分和现有图片任务存储；region_edit 使用 image_id 而非 image_urls，普通参考图数量仍为 0，不变更现有价格、RPC 或已执行迁移。免费素材准备不创建收费账单。

任何模型都不保证选区外像素完全不变。原有 GPT 服务商的真实接口兼容性、Grok Ext 账户权限和真实效果仍需另行授权收费验收；隔离模拟通过不能代替真实出片。

本轮验证使用合成素材、模拟上游及隔离账务；桌面与手机检查七种画框比例、六款模型编辑请求、蒙版像素、参考图上限和只提交一次。正式发布及回滚证据保留在本地 artifacts，不上传这些证据或交接文件。
