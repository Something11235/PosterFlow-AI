# 参考图选择与管理

主创作区支持分次追加参考图，不替换已有图片；最多保留8张，每张最多16 MiB，支持PNG、JPEG、WebP、GIF。选图时立即校验格式和大小，混选时保留符合要求的图片；超出剩余名额只忽略新增的多余图片。界面显示已选数量、继续添加按钮和明确的忽略原因。

每张预览右上角的×只删除该图，“清空全部参考图”移除整组。取消文件选择不会清空已选图片；文件输入每次读取后复位，因此删除后重新选择同一文件也能触发添加。重复选择按文件名、字节大小、最后修改时间和MIME识别，无需读取完整图片；这不是内容哈希去重，同名但修改时间或大小不同的文件可以继续添加。

图片按当前列表顺序对应`@图1`至`@图8`。删除后，提示词中指向被删图片的显式`@图N`标签会移除，后续有效标签顺次前移；普通“图N”文字和原本超出列表范围的标签不修改。清空时移除当前所有有效标签，其他提示词保留。管理员不需要修改任何数据库设置。

预览使用本机Blob URL；已有图片追加时不重新读取，删除或卸载时释放对应预览，避免先前异步FileReader回写旧列表。只有点击生成才按选定顺序进入既有压缩/直传/生图流程，选择和删除不创建远端图片或生成任务。生成中的请求保留提交时的图片快照，编辑选择用于下一次提交。

验证覆盖分次追加、去重、取消、单独删除及引用编号、重新添加、8张边界、混选格式/大小校验、预览URL释放、实际模拟上传顺序、桌面与手机布局。原有上传压缩和积分结算规则保留，本轮不涉及数据库迁移。
